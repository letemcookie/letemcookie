Let 'Em Cookie privacy

Let 'Em Cookie reads page elements locally to find and click cookie banners, and stores only its click-attempt count, first-share-screen state, and report preference in your browser; uninstalling removes those settings.

It sends no automatic analytics, browsing history, page text, or screenshots to us.

Missed-banner reporting is off by default: enabling it opens a GitHub issue draft whose URL sends GitHub the hostname, clicked selector, and extension version; you review and submit it yourself, and submitted issues are public.

X and Substack open only when you choose to share, and those services and GitHub apply their own privacy policies.

We do not sell user data or use it for advertising or credit decisions; our use follows the Chrome Web Store User Data Policy, including Limited Use requirements, and questions can go to chrisbest@mail.instinct.com.
